# Analysis and Diagnostic Outputs

This directory contains post-processing and diagnostic analysis scripts used to summarize and visualize the outputs of the core rotation-period pipeline. 

**No scientific inferences are made or modified at this stage.**

The scripts in this folder operate **exclusively** on the final, frozen rotation catalog generated by the Phase-2 pipeline (`data/processed/sector18_rotation_results_full.csv`). They do not perform light-curve processing, period detection, harmonic correction, or any decision-making that affects the final rotation-period assignments.

## Purpose of This Directory

The primary purpose of the `analysis/` directory is to:
* **Generate summary plots** describing the global properties of the derived rotation-period catalog.
* **Provide diagnostic visualizations** for quality assessment and transparency.
* **Support appendix-level figures** and sanity checks referenced in the manuscript.

These analyses are intended to illustrate pipeline behavior, classification outcomes, and population-level distributions, rather than to tune parameters or alter results.

## Contents

### `make_summary_plots.py`
This script generates high-level diagnostic figures, including:
* The overall rotation-period distribution.
* The fraction of stars assigned to each classification flag (`LS-only`, `Match`, `Harmonic-corrected`).
* Rotation-period distributions stratified by classification flag.

All figures produced by this script are saved to: `results/summary_plots/` and correspond to diagnostic and appendix figures discussed in the manuscript.

**Importantly:** This script does not re-run or modify the rotation analysis pipeline. It reads precomputed results only and is fully reproducible given the processed catalog.

## Scientific Scope and Limitations

The analyses performed here are **descriptive and diagnostic** in nature. They are **not** used to:
* Select or reject individual stars.
* Override Lomb–Scargle or ACF decisions.
* Optimize thresholds or hyperparameters.
* Influence planetary multiplicity comparisons.

All scientifically relevant decisions are made upstream in the **Phase-2 rotation pipeline** (`src/phase2_rotation_pipeline/`), ensuring a clear separation between inference and visualization.

## Reproducibility

All plots generated in this directory are fully reproducible using the fixed environment specified in `environment/requirements.txt` and the final processed rotation catalog.
