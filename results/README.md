This directory contains all figures and tables generated by the analysis
scripts in `analysis/`.

Subdirectories correspond to pipeline stages:

- `injection_validation/` — figures from injection–recovery experiments  
- `phase2_plots/` — diagnostic phase-folded light curves  
- `summary_plots/` — catalog-level summary figures  
- `validation_single_star/` — single-target validation examples  

All figures in the manuscript are reproducible from these scripts.
